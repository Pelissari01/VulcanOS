# 🌋 VulcanOS

**VulcanOS** é um projeto desenvolvido em Python com foco na aplicação prática de Programação Orientada a Objetos (POO).

O programa permite cadastrar vulcões, consultar informações, analisar níveis fictícios de risco e executar simulações de erupções por meio de uma interface interativa no terminal.

## ⚙️ Funcionalidades

- Cadastro de vulcões com nome e temperatura.
- Validação automática de temperatura (700°C a 1200°C).
- Consulta de vulcões registrados.
- Análise fictícia do nível de atividade vulcânica.
- Simulação de erupções.
- Remoção de vulcões após simulações concluídas.

## 🛠️ Tecnologias utilizadas

- Python 3.10+
- Programação Orientada a Objetos (POO).
- Biblioteca [Rich](https://github.com/Textualize/rich).
- Biblioteca Time (sleep).

## 📦 Instalação

1. Clone este repositório:

```bash
git clone URL_DO_SEU_REPOSITORIO
```

2. Instale a biblioteca Rich:

```bash
pip install rich
```

3. Execute o programa:

```bash
python main.py
```
